    Supported Features¶

    The complete matrix. means implemented and tested; means narrowed with a documented rule; means dropped by design, with a compile error naming the replacement.

    Version 0.1.0-SNAPSHOT. Milestones M1 through M4 are implemented, M5 is in progress.

    Statements¶

    Notes
    @Select @Insert @Update @Delete String[] value, joined with a single space
    <select> <insert> <update> <delete> in mapper XML Namespace = the interface FQN, id = the method name. Details
    Mixing annotations and XML in one mapper Resolved per method; having both or neither for a method is a compile error
    #{} bind parameters Resolved against the method's parameter types at build time
    ${} splices Only SqlFragment, closed-value types, or @OrderBy. Details
    @Param
    @Options(useGeneratedKeys, keyProperty, keyColumn) Details
    <selectKey> Write it as a second statement
    @SelectProvider / @InsertProvider family SQL built by a Java method at runtime is exactly what the generator cannot see
    Map or Object parameters Nothing to resolve #{} against. Use a parameter object or @Param arguments
    RowBounds In-memory paging over a full ResultSet. Page in SQL with LIMIT/OFFSET

    Dynamic SQL¶

    Notes
    <if> Compiled to a boolean local, evaluated once
    <choose> / <when> / <otherwise> Mutual exclusion compiled in
    <where> / <set> Constant-folded, not a runtime string scan
    <trim> Literal attributes only, folded at build time
    <sql> / <include> Static refid, inlined at build time
    <foreach> Statically-typed collections, arrays, maps. Empty collection throws. Details
    @PadPow2 Bounds IN-list SQL variants. Enforced to IN-list shape
    <bind> Introduces an OGNL variable. Compute it in Java and pass it in
    OGNL in test Replaced by a narrow grammar; truthiness is a compile error
    databaseId A databaseId attribute is a compile error. Give each database its own mapper interface

    Results¶

    Notes
    resultType with convention mapping snake_case → camelCase, at build time, always
    Positional row reads When the select list parses
    Name-based fallback SELECT * etc.; indexes resolved once from ResultSetMetaData
    Scalar results long, String, … read from column 1
    List<T> returns
    Stream<T> returns Caller closes. Details
    <resultMap> Explicit mappings only, no auto-mapping
    <association> / <collection> One level, via join, ResultSet ordered by parent key
    Nested select= in a result mapping That is the N+1 it claims to avoid. Write the join
    <discriminator> The result class would depend on a runtime value
    <constructor> results Result classes are built with a no-arg constructor and setters
    resultMap extends, columnPrefix, autoMapping Spell the mappings out
    Lazy loading Needs a proxy per result object
    Type aliases Use fully-qualified class names

    Types¶

    Notes
    Primitives and wrappers Wrappers go through JdbcCodec for null handling
    String, BigDecimal, BigInteger, byte[]
    java.sql.Date / Time / Timestamp
    Instant, LocalDate, LocalTime, LocalDateTime
    Enums (by name()) Also a closed-value type, so valid for ${}
    @Column Names the column on the field, the setter or the getter. Details
    @Handler custom handlers Named on the property, the parameter, or in mapper XML. Details
    <typeHandlers>, one handler per Java type Written out as -Alarkbatis.typeHandlers pairs and resolved during javac. Details
    TypeHandler discovery (<package>, @MappedTypes) Nothing is scanned. The list is written out, which is also what makes it readable

    Sessions, transactions, execution¶

    Notes
    LarkBatisTx scopes, nesting, vote-to-commit Details
    Spring @Transactional Via DataSourceUtils
    Spring exception translation SQLExceptionSubclassTranslator by default
    Spring Boot auto-configuration Boot 3 and Boot 4 from one jar
    Generated Spring @Configuration proxyBeanMethods = false
    Batch inserts A method signature (List<T> parameter), not an executor mode
    Multi-row VALUES via <foreach>
    The escape hatch (query, queryOne, queryStream, update) Takes SqlFragment, never String
    ExecutorType.BATCH / REUSE There is no executor
    Plugins / interceptors The four objects MyBatis intercepts are what a generated body replaces, and the mechanism is a JDK proxy. What replaces a plugin
    Second-level cache (<cache>, <cache-ref>) Cache above the mapper, where invalidation is visible
    First-level cache No session to hold it
    Runtime addMapper() The mapper set is closed at compile time
    Multiple DataSources per mapper Deferred. Declare one session per DataSource and write the @Bean methods yourself
    SQL logging (log-sql) Belongs to the driver or the pool: datasource-proxy, p6spy

    Build and packaging¶

    Notes
    Annotation processor (javac) javac only; ECJ is not supported
    Gradle plugin Details
    Maven plugin Needs <extensions>true</extensions>
    JPMS named modules All five published artifacts
    Lombok interoperability Declare the LarkBatis processor after Lombok
    Incremental builds Aggregating processor; compile with -parameters under Gradle
    Test-scoped mappers Only the compile source set is wired
    GraalVM native image Structurally ready, with no reflection to declare, but not yet verified by a real build
    Legacy-mapper scanner larkbatis-scan. Details
